# SiroAI

AI notebook app — upload sources, ask questions, get answers with citations.

**Live:** https://siro-ai-nu.vercel.app/

**GitHub:** https://github.com/sampleritzgod/siroAI

## Run locally

```bash
pnpm install
cp .env.example .env.local
pnpm db:deploy
pnpm dev
```

Open http://localhost:3000
